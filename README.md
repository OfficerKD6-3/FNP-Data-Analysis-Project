# Ferns and Petals (FNP) Sales Analysis – Excel Dashboard

## Project Overview

This project focuses on analyzing the sales performance of **Ferns and Petals (FNP)** using Microsoft Excel.

FNP is a gifting company that delivers products for various occasions such as **Diwali, Raksha Bandhan, Holi, Valentine's Day, Birthdays, and Anniversaries**.

The objective of this project is to analyze sales, customer spending, product performance, delivery time, cities, and occasions to identify meaningful business insights and support data-driven decision-making.

---

## Project Objective

The main objective of this project is to analyze the FNP sales dataset and build an **interactive Excel dashboard** that provides insights into:

* Overall revenue performance
* Monthly sales trends
* Customer spending behavior
* Product performance
* Delivery time
* Top-performing cities
* Revenue by occasion
* Relationship between order quantity and delivery time

## Project Insights

### 1. Overall Sales Performance

The FNP dataset generated a total revenue of approximately **₹35.21 lakh** from **1,000 orders**.

The average order value was approximately **₹3,521**.

### 2. Monthly Sales Performance

Revenue varied significantly across the months.

Based on the analysis, the highest revenue-generating months were:

* **August – ₹7,37,389**
* **February – ₹7,04,509**
* **March – ₹5,11,823**

This shows that sales performance was not evenly distributed throughout the year.

### 3. Top Revenue-Generating Products

The highest revenue-generating products included:

* **Magnam Set – ₹1,21,905**
* **Dolores Gift – ₹1,06,624**
* **Harum Pack – ₹1,01,556**
* **Deserunt Box – ₹97,665**
* **Nostrum Box – ₹97,656**

These products contributed significantly to overall revenue.

### 4. Customer Spending

The average revenue generated per order was approximately **₹3,521**, providing an indication of the typical customer order value in the dataset.

### 5. Top Cities by Number of Orders

The cities with the highest number of orders included:

* **Ghaziabad – 9 orders**
* **Bareilly – 9 orders**
* **Bhilai – 8 orders**
* **Darbhanga – 7 orders**
* **Sirsa – 7 orders**
* **Bulandshahr – 7 orders**
* **Ozhukarai – 7 orders**
* **Varanasi – 7 orders**
* **Alwar – 7 orders**
* **Satara – 7 orders**

### 6. Order Quantity vs. Delivery Time

The analysis examined whether larger order quantities were associated with longer delivery times.

The calculated correlation between **order quantity and delivery time was approximately 0.0035**, indicating almost no linear relationship in this dataset.

Therefore, within this dataset, order quantity alone does not show a meaningful linear association with delivery duration.

### 7. Revenue by Occasion

Revenue generated across different occasions was:

| Occasion        |   Revenue |
| --------------- | --------: |
| Anniversary     | ₹6,74,634 |
| Raksha Bandhan  | ₹6,31,585 |
| All Occasions   | ₹5,86,176 |
| Holi            | ₹5,74,682 |
| Birthday        | ₹4,08,194 |
| Valentine's Day | ₹3,31,930 |
| Diwali          | ₹3,13,783 |

This provides a clear view of how revenue is distributed across different gifting occasions.
